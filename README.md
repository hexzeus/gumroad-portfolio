# Gumroad Creator-in-Residence Portfolio

1. Copy all your photos into `src/assets/photos/` (jpg, png, webp). They sort by filename (1, 2, 10 sort naturally).
2. Edit `PROFILE` at the top of `src/App.jsx` (name, bio, email).
3. `npm install` then `npm run dev` to preview, `npm run build` to verify.
4. Push to GitHub (hexzeus) and import the repo in Vercel. Framework preset: Vite. No other settings needed.

Tip: keep each photo under ~2 MB for fast loading.
